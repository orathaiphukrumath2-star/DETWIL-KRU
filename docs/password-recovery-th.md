# กู้บัญชี DETWIL โดยไม่ใช้ OTP

## สมาชิก

1. ที่หน้าเข้าสู่ระบบ เลือก **ลืมรหัสผ่าน** แล้วกรอกอีเมลที่สมัคร
2. ติดต่อผู้ดูแลผ่านช่องทางที่รู้จักเพื่อยืนยันตัวตน ระบบไม่ส่งอีเมลเอง และข้อความรับคำขอไม่ได้ยืนยันว่าพบอีเมลในระบบ
3. รับลิงก์ส่วนตัวจากผู้ดูแล เปิดภายใน 15 นาที กรอกอีเมลและตั้งรหัสใหม่ 12–128 ตัวอักษร ยืนยันให้ตรงกัน
4. เข้าระบบใหม่ตามปกติ อุปกรณ์ที่เข้าสู่ระบบไว้ก่อนหน้านี้จะต้องเข้าสู่ระบบใหม่ด้วย

ห้ามส่งรหัสผ่านให้ผู้ดูแลหรือในแชต ลิงก์เป็นความลับ ให้ส่งเฉพาะเจ้าของบัญชี ไม่ส่งในกลุ่ม ไม่เก็บใน Git หรือเอกสารสาธารณะ

## ผู้ดูแล

เลือกบทบาท Super Admin ใน `/studio` เปิดส่วนจัดการสมาชิก แล้วดู **คำขอตั้งรหัสใหม่** รายการโหลดครั้งเดียวและมีปุ่มโหลดใหม่ ไม่มีการ polling

**ห้ามยืนยันจากอีเมลที่พิมพ์มาอย่างเดียว** ต้องตรวจด้วยช่องทางที่ยืนยันได้ เช่น ติดต่อครูผ่านผู้ประสานงานโรงเรียนหรือข้อมูลที่มีอยู่เดิม เมื่อยืนยันแล้วจึงติ๊กยืนยันตัวตนและออกลิงก์ ส่งส่วนตัวให้เจ้าของบัญชี ผู้ดูแลไม่ต้องตั้งหรือทราบรหัสใหม่

ลิงก์แสดงครั้งที่ออกเท่านั้น โหลดหน้าใหม่แล้วอ่าน token เดิมกลับจากชีตไม่ได้ ออกลิงก์ใหม่ได้แต่จะยกเลิกลิงก์เก่าทันที การส่งคำขอซ้ำจากหน้าสาธารณะไม่ยกเลิกลิงก์ที่ยังใช้ได้

## เปิดใช้ตารางครั้งแรก

หลังอัปโหลดโค้ด ให้เจ้าของโปรเจกต์ Google รัน `DETWIL_preparePasswordRecovery` จาก Apps Script Editor ตรวจผล `ready: true` และตาราง `PASSWORD_RESET_REQUESTS` แล้วเผยแพร่ version ใหม่บน deployment เดิม

ฟังก์ชันนี้ตรวจหัวตารางเดิมก่อนเขียน ไม่ลบข้อมูลหรือเปลี่ยนรหัสผ่าน หากพบ `SCHEMA_MISMATCH` ให้ตรวจหัวคอลัมน์ ไม่เปลี่ยนหัวตารางทับข้อมูลเอง

## หากผู้ดูแลเข้าเว็บไม่ได้

ใช้บัญชี Google เจ้าของระบบที่มี Super Admin และยังเปิดใช้งาน:

1. เปิดโปรเจกต์ Apps Script เดิม เข้า Project Settings → Script Properties
2. เพิ่ม `DETWIL_RECOVERY_TARGET_EMAIL` เป็นอีเมลบัญชีที่ตรวจตัวตนแล้ว
3. กลับ Editor รัน `DETWIL_issueEditorPasswordReset`
4. เปิดลิงก์จาก execution log ส่วนตัว ให้เจ้าของบัญชีกรอกรหัสใหม่เอง ฟังก์ชันลบ property เป้าหมายหลังออกลิงก์สำเร็จ

บัญชี Super Admin กู้ผ่านทางนี้ได้เฉพาะบัญชีของ Google owner ที่กำลังรัน ไม่กู้ Super Admin คนอื่นผ่านหน้าเว็บ

หากเป็นบัญชีผู้ดูแลเริ่มต้นที่ **ยังไม่เคยมีรหัสผ่าน** ให้รัน `DETWIL_prepareWorkSystem` เพื่อเปิดใช้งานครั้งแรก ไม่สมัครซ้ำและไม่ใช้ recovery แทน activation

## การเก็บข้อมูลและข้อจำกัด

- ชีตเก็บ `TokenHash` และ fingerprint ของ credential ไม่เก็บ token ดิบ ลิงก์ หรือรหัสผ่านจริง
- คำขอไม่เปลี่ยนรหัส ไม่ปลดระงับบัญชี ไม่อนุมัติบทบาท และไม่ยกเลิก session จนตั้งรหัสใหม่สำเร็จ
- ตรวจ token/อีเมล/อายุ/สถานะบัญชีและ credential ภายใต้ lock ลิงก์ใช้ครั้งเดียว การเปลี่ยนรหัสภายหลังทำให้ลิงก์เก่าใช้ไม่ได้
- ตอนตั้งรหัสใหม่ ยกเลิก session ก่อนเขียน credential; fingerprint ป้องกันใช้ token ซ้ำหากการเขียนสถานะคำขอล้มเหลวภายหลัง Google Sheets ไม่มี transaction หากแจ้งผิดพลาดระหว่างบันทึก ให้ลองเข้าสู่ระบบด้วยรหัสใหม่ก่อนขอลิงก์อีกครั้ง
- ไม่มี OTP ไม่มีการตรวจเจ้าของอีเมลอัตโนมัติ และไม่มีอีเมลแจ้งเปลี่ยนรหัส จึงต้องตรวจตัวตนและแจ้งผลด้วยคน ไม่ใช่ระบบกู้บัญชีอัตโนมัติเต็มรูปแบบ
- เว็บจำกัดความถี่ต่อ IP แบบ memory ต่อ Vercel instance; Apps Script URL ยังเรียกตรงได้ จึงยังต้องเพิ่มการป้องกัน abuse และ distributed throttling ก่อนเปิดวงกว้าง
- ข้อความตอบกลับไม่เปิดเผยการมีบัญชี แต่เวลาอ่าน Sheets ยังแตกต่างกันได้ ไม่รับรอง constant-time response
- หน้า reset ไม่ทำ index และใช้นโยบาย no-referrer แต่ URL อาจอยู่ในประวัติเบราว์เซอร์หรือ access log ของผู้ให้บริการ อย่าส่งลิงก์ให้บุคคลอื่น

ออกแบบตามหลัก token สุ่ม อายุสั้น ใช้ครั้งเดียว และ hash ของ [OWASP Forgot Password Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html) โดยใช้ผู้ดูแลตรวจตัวตนและส่งลิงก์เองแทนบริการอีเมล
