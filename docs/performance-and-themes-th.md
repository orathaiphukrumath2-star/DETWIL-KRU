# ความเร็ว ระดับชั้น และธีมชุดผลงาน

รุ่น 0.6.0 ใช้ฐานข้อมูลเดิม 30 ตาราง ไม่ต้องสร้างชีตเพิ่มหรือรัน migration

## สิ่งที่ปรับ

- เปิดพื้นที่ผลงานด้วย `workspace` ซึ่งคืนบัญชี รายการผลงานและสถานศึกษาพร้อมกัน จากเดิม `session` แล้ว `myWorks` แยกสองรอบ
- การเข้าสู่ระบบด้วยรหัสผ่านส่ง `includeWorkspace: true` และรับพื้นที่ทำงานในผลเดียว โดยยังใช้ scrypt และ cookie แบบเดิม ไม่ลดความแข็งแรงของรหัสผ่าน
- `saveWork` อัปเดตหน้าปัจจุบันจากผลตอบกลับที่บันทึกสำเร็จ ไม่เรียก `myWorks` ซ้ำหลังบันทึกแต่ละครั้ง การตรวจรับรองก็ใช้ผลตอบกลับเดียว พร้อมประวัติ ไม่เรียก `getWork` และรายการซ้ำ
- อัปโหลดผ่าน `attachFile` เพื่อตรวจรุ่นและสิทธิ์ แนบไฟล์และบันทึกชุดผลงานในคำขอเดียว ไฟล์ยังอยู่ใน Drive ส่วนตัว และยังจำกัด 2 MB
- Repository เปิด Spreadsheet และอ่านหัวตารางซ้ำเพียงครั้งต่อคำขอ เก็บแถวที่อ่านไว้ชั่วคราวเฉพาะคำขอนั้น คืนสำเนาแถวให้ผู้เรียก และล้างข้อมูลที่เขียนแล้วก่อนอ่านซ้ำ
- ล้าง cache เมื่อจบ HTTP ทั้งสำเร็จและล้มเหลว ไม่ใช้ CacheService เก็บบัญชี/session/บทบาทข้ามคำขอ การเขียนตรวจสิทธิ์หลังได้ lock จึงไม่ใช้สิทธิ์ก่อนรอ lock มายืนยันการเขียน
- รายการเรียงผลงานใหม่ก่อน หากสร้างใหม่ขณะอยู่หน้ารายการลึก ระบบโหลดหน้าแรกเมื่อกลับไปรายการ ไม่เพิ่มคำขอในขั้นบันทึก

แนวทางลดการเรียกบริการและรวมการอ่านข้อมูลสอดคล้องกับ [Apps Script Best Practices](https://developers.google.com/apps-script/guides/support/best-practices) แต่ **ไม่ได้ทำให้ Apps Script ไม่มีความหน่วงหรือโควต้า** เวลาเริ่มทำงาน การรับ/ส่งไฟล์ Drive เครือข่าย และ lock ยังมีผล ต้องทดสอบโหลดจริงก่อนรับรองจำนวนผู้ใช้พร้อมกัน

ก่อนปรับ วัด API รายการสาธารณะหนึ่งครั้งได้ 5,712 ms การวัดนี้เป็นเพียงตัวอย่าง ไม่ใช่ค่าเฉลี่ยหรือเวลา login และไม่ใช้เป็นหลักฐานว่าทุกกรณีจะเร็วขึ้นตามเปอร์เซ็นต์เดียวกัน

## ใช้งานธีมและปุ่มเนื้อหา

1. เปิดชุดผลงาน ระดับชั้นเลือกได้ตั้งแต่ชั้นมัธยมศึกษาปีที่ 1–6 รองรับค่าเก่าอย่าง `M1` และ `ม.1` เมื่อแก้ไข
2. แต่ละหมวดแผน สื่อ ผลงานผู้เรียน และหลักฐาน มีปุ่ม **เพิ่มไฟล์ / ลิงก์** พร้อมเลือกหมวดให้ และมีปุ่ม **เปิดเนื้อหา / เปิดไฟล์** ในรายการ
3. ลิงก์เพิ่มในแบบร่างทันที ต้องกดบันทึกเพื่อเก็บบนชีต ส่วนไฟล์อัปโหลดจะบันทึกชุดผลงานรวมไปด้วย จึงต้องกรอกข้อมูลบังคับให้ครบและมีฉบับร่างก่อน
4. PDF และภาพ raster เปิดในแท็บใหม่ได้ผ่าน API ที่ตรวจสิทธิ์ ไฟล์ Office ดาวน์โหลดตามปกติ ไม่เปิด HTML หรือ SVG บน origin เว็บไซต์
5. ส่วน 04 เลือกธีม **เรียบง่ายเป็นทางการ / สีสันสร้างสรรค์ / บันทึกการเรียนรู้** และสีหลัก 5 สี กด **ดูตัวอย่างรูปแบบ** ได้ทันทีโดยไม่บันทึกหรือเรียก Google
6. กดบันทึกก่อนส่งตรวจ ธีมและสีเก็บใน `WORKS.ContentJson` และ `RECORD_VERSIONS.SnapshotJson` เมื่อผ่านโรงเรียนและเขตแล้วจึงไปอยู่ใน snapshot สาธารณะ

ธีมไม่เพิ่มสิทธิ์เผยแพร่ หลักฐานผู้เรียนยังเป็นส่วนตัวตามค่าเริ่มต้น และการแก้ธีมหรือสีหลังเผยแพร่สร้างฉบับร่างใหม่ซึ่งต้องตรวจซ้ำ รูปแบบสาธารณะเดิมยังคงอยู่จนเผยแพร่ฉบับใหม่

Google Sheets/Drive ไม่มี transaction ร่วมกัน หากเกิดข้อผิดพลาดหลังสร้างไฟล์แต่ก่อนบันทึกเสร็จ อาจมีไฟล์ที่ยังไม่ผูกกับผลงาน การทำงานล้างไฟล์ค้างและ distributed rate limiting ยังอยู่ในงานถัดไป ไม่ retry การอัปโหลดอัตโนมัติ

การทดสอบใช้ fixtures ไม่สร้างสมาชิก/ผลงานตัวอย่างใน production และไม่ปิดการตรวจสิทธิ์ของเว็บจริง
