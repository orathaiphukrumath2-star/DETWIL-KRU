# หน้าแรกและแดชบอร์ด DETWIL

ปรับหน้าแรกจากหน้าสถานะการพัฒนาเป็นหน้าแสดงชื่อระบบ วัตถุประสงค์ และภาพรวมผลงานครู ใช้โลโก้หน่วยงานทั้งสองดวงจากไฟล์ที่เจ้าของระบบให้มา ภาพต้นฉบับเก็บใน `web/public/images/agency-logos.png` โดยไม่ได้แก้รายละเอียดตรา

## ส่วนที่เพิ่ม

- ชื่อ DETWIL และชื่อระบบภาษาไทย/อังกฤษ
- ภาพรวมสถานศึกษา ครู ผลงาน และการรับรอง
- พื้นที่กราฟแยกประเภทผลงานและเส้นทางการรับรอง
- คลังผลงานพร้อมตัวกรองประเภท ปีการศึกษา และช่องค้นหา
- เครือข่ายสถานศึกษาและวัตถุประสงค์ 4 ด้าน
- เมนูมือถือ สถานะข้อมูลว่าง และตัวตรวจการเชื่อมต่อที่ท้ายหน้า

## ความหมายของข้อมูลที่แสดง

31 โรงเรียนมาจากขอบเขตโครงการที่ยืนยันแล้ว ไม่ใช่จำนวนแถวที่อ่านจาก SCHOOLS ตัวเลขครู ผลงาน และการรับรองแสดงขีดและข้อความรอข้อมูล ไม่มีการสร้างยอดสมมติหรือเติมข้อมูลลงชีต

กราฟและรายการผลงานยังเป็นสถานะว่าง ฝั่งเว็บยังไม่มี endpoint สำหรับดึงสถิติหรือรายการผลงานจากชีต ตัวกรองเปลี่ยนเงื่อนไขและข้อความสถานะบนหน้าเว็บเท่านั้น การเติมชีตอย่างเดียวยังไม่ทำให้สถิติในหน้าใหม่นี้อัปเดต จนกว่าจะพัฒนาการอ่านข้อมูลต่อ

สถานะเชื่อมต่อที่ท้ายหน้าอ้างอิง health check เดิมของ Google Apps Script ซึ่งตรวจ Spreadsheet, Drive root และ schema ไม่ใช่การยืนยันว่ามีข้อมูลผลงานแล้ว

## งานหลังบ้านที่ต้องเชื่อมต่อ

ข้อมูลโรงเรียนจาก SCHOOLS, ครูจาก TEACHER_PROFILES/USERS, ผลงานจาก MEDIA/LESSON_PLANS/OBEC_USAGE/RESEARCH และการรับรองตามสิทธิ์ที่กำหนด ต้องผ่าน backend ที่แยกข้อมูลสาธารณะกับข้อมูลส่วนบุคคล

รายการตัวกรองปีการศึกษาและข้อความวัตถุประสงค์เป็นค่าฝั่งเว็บในรุ่นนี้ สามารถเชื่อม SETTINGS/MASTER_DATA ในงานหลังบ้านลำดับถัดไป
